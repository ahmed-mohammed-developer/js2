  # وصف المشروع: معرض الصور التفاعلي (Carousel)

مشروع معرض الصور التفاعلي هو واجهة ويب تتيح للمستخدم استعراض مجموعة من الصور والمحتويات بطريقة منظمة وجذابة، مع إمكانية التنقل بين الشرائح باستخدام أزرار السابق والتالي أو النقاط الموجودة أسفل المعرض.

تم تطوير المشروع باستخدام **HTML وCSS وJavaScript**، حيث استُخدم HTML لبناء هيكل الصفحة، وCSS لتنسيق التصميم وجعله متجاوبًا مع مختلف أحجام الشاشات، وJavaScript لإضافة التفاعل والتحكم في عرض الشرائح.

يتضمن المشروع مجموعة من المميزات، منها التنقل اليدوي بين الصور، والتشغيل التلقائي مع إمكانية إيقافه أو تشغيله، وإيقاف التنقل التلقائي عند تمرير المؤشر فوق المعرض أو التركيز على عناصره، بالإضافة إلى مراعاة إعدادات المستخدم لتقليل الحركة وتحسين إمكانية الوصول.

يهدف المشروع إلى تطبيق مفاهيم تطوير واجهات المستخدم، والتعامل مع عناصر DOM والأحداث والمؤقتات في JavaScript، مع الاهتمام بتجربة المستخدم وسهولة الاستخدام وإمكانية الوصول.
